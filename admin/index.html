    This device stays signed in with your GitHub key until you press Sign out.

    To change the key: create a new one on GitHub, sign out here, and sign in with the new key. Then delete the old key on GitHub.

    Lost a phone or laptop? Delete its key on GitHub (Settings → Developer settings → Personal access tokens). That device then can’t change the website any more.
